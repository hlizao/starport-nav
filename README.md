# 星港导航 Starport

一个纯静态单文件的个人导航站（深色科技感），附带完整的「本地服务 + Cloudflare 免注册隧道」公网部署方案与一键脚本。

## 功能特性

- **指挥台首页**：实时时钟 + 分时段问候语，`/` 或 `Ctrl+K` 一键聚焦搜索
- **五个搜索引擎切换**：百度 / 必应 / 知乎 / B站 / 微博；输入网址直接跳转
- **两组站点卡片**：办公协同（邮箱/文档/网盘/会议）+ 娱乐与生活（视频/音乐/购物/出行）
- **完全可定制**：编辑模式增删改链接（带撤销、可恢复默认），右下角自动保存便签
- **零依赖离线可用**：无外部字体/框架，数据仅存本机浏览器 localStorage
- **公网部署方案**：免注册隧道一键上线，互联网任意设备可访问

## 文件结构

```
├── index.html                  # 导航站本体（单文件，双击即用）
├── deploy/
│   ├── start-nav.ps1           # 一键部署脚本（停旧→起新→取公网地址→开浏览器）
│   ├── keepalive-nav.ps1       # 保活检查脚本（异常自动重新部署）
│   └── 启动导航站.bat           # 双击入口
└── docs/
    └── 星港导航站公网部署技术文档.md   # 完整部署与复现指南
```

## 快速开始

1. **本地使用**：直接用浏览器打开 `index.html` 即可。
2. **公网部署**：按 `docs/` 中的技术文档操作，或把 `deploy/` 下三个文件与导航站放在同一目录，下载并校验 [cloudflared](https://github.com/cloudflare/cloudflared/releases/latest) 后双击 `启动导航站.bat`，即可获得一个 `https://xxxx.trycloudflare.com` 公网地址。
3. **个性化**：页面右上角「编辑」按钮增删站点，右上角「便签」随手记录，所有修改自动保存在浏览器本地。

> 部署涉及 SHA-256 校验、端口绑定、进程精确匹配等细节，务必先阅读技术文档。

## 环境

- 浏览器直接打开：无任何依赖
- 公网部署：Windows + Python 3.6+（自带 http.server）+ cloudflared
