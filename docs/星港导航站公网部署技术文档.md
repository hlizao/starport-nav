# 星港导航站公网部署技术文档

[TOC]

## 一、方案概述

### 1.1 项目背景

「星港 · Starport」是一个纯静态单文件个人导航站（`个人导航站.html`，约 28KB，含 HTML/CSS/JS），无需服务器渲染、无外部依赖。部署目标：**在局域网机器上运行，使互联网上的任意设备（手机/其他电脑）均可通过 HTTPS 访问**，且不要求本机具备公网 IP。

### 1.2 架构原理

部署采用「本地静态服务 + Cloudflare 免注册隧道」两层结构：

```
互联网用户浏览器
      │ HTTPS 443
      ▼
Cloudflare 边缘节点（trycloudflare.com 临时域名）
      │ 加密隧道（出站连接，无需公网IP、无需端口映射）
      ▼
本机 cloudflared 隧道进程
      │ HTTP 127.0.0.1:8931（仅本机回环，不对外暴露）
      ▼
本机 Python HTTP 服务（仅服务 nav-deploy 目录）
      │
      ▼
nav-deploy\index.html（导航站静态文件）
```

**关键特性**：

| 特性 | 实现方式 |
|------|---------|
| 无需公网 IP | cloudflared 与 Cloudflare 建立出站隧道连接 |
| 无需注册账号 | 使用 trycloudflare.com 免注册 Quick Tunnel |
| 只暴露单页面 | HTTP 服务仅绑定 127.0.0.1 且 `--directory` 指定独立目录 |
| 工具可信 | 下载后做 SHA-256 校验，与官方发布值比对 |
| 自动保活 | 定时任务每 15 分钟探测，异常自动重启 |

### 1.3 部署产物清单

| 文件 | 说明 |
|------|------|
| `个人导航站.html` | 导航站源文件（业务本体） |
| `nav-deploy\index.html` | 部署副本（由源文件复制，HTTP 服务仅暴露此目录） |
| `.temp\tools\cloudflared.exe` | Cloudflare 隧道工具（约 53MB，需 SHA-256 校验） |
| `start-nav.ps1` | 一键部署脚本（停旧→启新→取地址→写文件→开浏览器） |
| `keepalive-nav.ps1` | 保活检查脚本（探测→异常时调用一键部署） |
| `启动导航站.bat` | 双击入口（调用 start-nav.ps1） |
| `导航站公网地址.txt` | 当前有效公网地址（每次部署自动更新） |

## 二、环境要求

| 项目 | 要求 | 本部署环境实测 |
|------|------|--------------|
| 操作系统 | Windows 10/11 或 Windows Server | Windows（PowerShell 5.1） |
| Python | 3.6+（自带 `http.server` 模块） | Python 3.12.13 |
| 网络 | 能出站访问 443 端口；可访问 Cloudflare/镜像站 | 已验证 |
| 可选：Node.js | 不需要（仅文档生成用到） | v24.18.0 |
| 磁盘 | 100MB 空闲（隧道工具 53MB） | — |

**网络连通性预检**（部署前在目标机器执行）：

```powershell
foreach ($h in 'www.baidu.com','github.com','www.cloudflare.com') {
  $r = Test-NetConnection -ComputerName $h -Port 443 -WarningAction SilentlyContinue
  "$h -> $($r.TcpTestSucceeded)"
}
```

三项均返回 `True` 即可继续；若 `github.com` 为 False，直接使用第 4.2 节的镜像下载路径。

## 三、分步部署操作

以下步骤为**手动完整流程**（与一键脚本等效），适合首次部署或排查时逐步执行。假设工作目录为 `D:\Data\TeleAgent的工作空间`，其他机器请替换为实际路径。

### 3.1 准备站点目录

创建独立部署目录，只放入需要公开的文件，与工作区其他文件隔离：

```powershell
New-Item -ItemType Directory -Path 'nav-deploy' -Force
Copy-Item '个人导航站.html' 'nav-deploy\index.html' -Force
Get-ChildItem 'nav-deploy'   # 确认仅 index.html 一个文件
```

> **安全要点**：HTTP 服务根目录必须是这个专用目录。若直接以工作区为根目录，会把其他文件一并暴露到公网。

### 3.2 获取 cloudflared 隧道工具

**官方发布页**：https://github.com/cloudflare/cloudflared/releases/latest ，下载 `cloudflared-windows-amd64.exe`（约 53MB）。

**优先路径 A —— GitHub 直连**（网络通畅时）：

```powershell
curl.exe -sSL --retry 3 --connect-timeout 30 -o '.temp\tools\cloudflared.exe' `
  'https://github.com/cloudflare/cloudflared/releases/latest/download/cloudflared-windows-amd64.exe'
```

**备用路径 B —— 加速镜像**（直连超时/限速时使用，本部署实际采用此路径）：

```powershell
$src = 'https://github.com/cloudflare/cloudflared/releases/latest/download/cloudflared-windows-amd64.exe'
foreach ($m in 'https://ghfast.top/','https://gh-proxy.com/','https://ghproxy.net/') {
  $null = curl.exe -sSL --connect-timeout 15 -m 200 -o '.temp\tools\cf-tmp.exe' ($m + $src)
  if ($LASTEXITCODE -eq 0 -and ((Get-Item '.temp\tools\cf-tmp.exe').Length -gt 40MB)) { break }
}
```

**强制校验 SHA-256**（防止镜像投毒，不可跳过）：

先从官方 release 页面「SHA256 Checksums」区获取当前版本 `cloudflared-windows-amd64.exe` 的校验值（本部署时 2026.11.1 版为 `341deda3db5ec498a0482254d6c38c0b7cf01a30c37bb5dd95d2216d08955e35`，**版本更新后该值会变化，务必以官方页面为准**），然后比对：

```powershell
$expected = '<官方页面查到的当前值>'
$hash = (Get-FileHash '.temp\tools\cf-tmp.exe' -Algorithm SHA256).Hash
if ($hash -eq $expected) {
  Move-Item '.temp\tools\cf-tmp.exe' '.temp\tools\cloudflared.exe' -Force
  "校验通过"
} else { "校验失败，删除可疑文件"; Remove-Item '.temp\tools\cf-tmp.exe' -Force }
```

> 本部署实测记录：GitHub 直连 HEAD 请求可通但 GET 下载被限速至约 8KB/s 并超时；切换镜像后一次成功且校验一致。

### 3.3 启动本地 HTTP 服务

```powershell
python -m http.server 8931 --bind 127.0.0.1 --directory "D:\Data\TeleAgent的工作空间\nav-deploy"
```

参数说明：

| 参数 | 作用 |
|------|------|
| `8931` | 服务端口（可改，需同步改脚本） |
| `--bind 127.0.0.1` | 仅本机回环可访问，隧道进程之外无人能直连 |
| `--directory` | 服务根目录锁定为部署目录 |

后台静默方式启动（推荐，写入独立日志）：

```powershell
Start-Process -FilePath 'python' -ArgumentList @('-m','http.server','8931','--bind','127.0.0.1','--directory','"nav-deploy 的绝对路径"') -WindowStyle Hidden
```

验证本地服务：

```powershell
Invoke-WebRequest -Uri 'http://127.0.0.1:8931/' -UseBasicParsing -TimeoutSec 5
# 预期 HTTP 200，内容长度 28152 字节
```

### 3.4 启动公网隧道并获取地址

```powershell
.temp\tools\cloudflared.exe tunnel --url http://127.0.0.1:8931 --no-autoupdate --protocol http2
```

参数说明：

| 参数 | 作用 |
|------|------|
| `tunnel --url` | 免注册 Quick Tunnel，指向本地服务 |
| `--no-autoupdate` | 禁止自动更新（防止生产环境意外变更二进制） |
| `--protocol http2` | 使用 HTTP/2 而非 QUIC，兼容性更好 |

隧道进程启动后**保持前台运行不关闭**，日志中出现 `Registered tunnel connection` 即成功。从日志中提取公网地址：

```powershell
# 假设隧道输出重定向到了 .temp\cloudflared-latest.log
$url = Select-String -Path '.temp\cloudflared-latest.log' -Pattern 'https://[a-z0-9-]+\.trycloudflare\.com' -AllMatches |
       ForEach-Object { $_.Matches.Value } | Select-Object -First 1
$url
# 形如 https://xxxx-xxxx-xxxx-xxxx.trycloudflare.com
```

### 3.5 公网验证

```powershell
Invoke-WebRequest -Uri '<上一步获取的公网地址>' -UseBasicParsing -TimeoutSec 30
# 预期 HTTP 200，返回字节数与 index.html 文件大小一致
```

再用手机或其他设备浏览器打开该地址，确认页面完整渲染（时钟走动、卡片显示）。若返回 `530`，属隧道刚注册、边缘节点尚未传播完成，等待 15–30 秒重试即可。

## 四、一键部署脚本（完整源码）

将以下三个文件放在同一目录（本部署为工作区根目录），双击 `启动导航站.bat` 即完成「停旧服务 → 起新服务 → 取新地址 → 更新地址文件 → 打开浏览器」全流程。

### 4.1 start-nav.ps1（核心部署脚本）

```powershell
# ================================================
#  星港导航 · 一键部署（本地服务 + 公网隧道）
#  用法：双击「启动导航站.bat」，或右键本文件选择"使用 PowerShell 运行"
# ================================================
param([switch]$NoBrowser)
$ErrorActionPreference = 'Stop'
$Root      = Split-Path -Parent $MyInvocation.MyCommand.Path
$DeployDir = Join-Path $Root 'nav-deploy'
$Tool      = Join-Path $Root '.temp\tools\cloudflared.exe'
$UrlFile   = Join-Path $Root '导航站公网地址.txt'
$CfLog     = Join-Path $Root '.temp\cloudflared-latest.log'
$Port      = 8931

if (-not (Test-Path (Join-Path $DeployDir 'index.html'))) { Write-Host '未找到 nav-deploy\index.html，请先确认目录'; exit 1 }
if (-not (Test-Path $Tool)) { Write-Host '未找到隧道工具，请确认 .temp\tools\cloudflared.exe 存在'; exit 1 }

# 1) 停止旧实例（仅匹配本部署的特征进程，不影响其他程序）
Get-CimInstance Win32_Process -Filter "Name='python.exe'" |
  Where-Object { $_.CommandLine -like '*http.server*' -and $_.CommandLine -like "*$Port*" } |
  ForEach-Object { taskkill.exe /PID $_.ProcessId /T /F 2>$null | Out-Null }
Get-CimInstance Win32_Process -Filter "Name='cloudflared.exe'" |
  Where-Object { $_.CommandLine -like "*127.0.0.1:$Port*" } |
  ForEach-Object { taskkill.exe /PID $_.ProcessId /T /F 2>$null | Out-Null }
Start-Sleep -Seconds 1

# 2) 启动本地服务（只服务 nav-deploy 目录，仅绑定本机回环地址）
Start-Process -FilePath 'python' -ArgumentList @('-m','http.server',"$Port",'--bind','127.0.0.1','--directory',('"{0}"' -f $DeployDir)) -WindowStyle Hidden

# 3) 启动 Cloudflare 免注册隧道（日志写入 .temp\cloudflared-latest.log）
Remove-Item $CfLog -Force -ErrorAction SilentlyContinue
$cmdArgs = '/c {0} tunnel --url http://127.0.0.1:{1} --no-autoupdate --protocol http2 > "{2}" 2>&1' -f $Tool, $Port, $CfLog
Start-Process -FilePath $env:ComSpec -ArgumentList $cmdArgs -WindowStyle Hidden

# 4) 等待隧道分配公网地址（最多约 50 秒）
$url = $null
for ($i = 0; $i -lt 25; $i++) {
  Start-Sleep -Seconds 2
  if (Test-Path $CfLog) {
    $u = Select-String -Path $CfLog -Pattern 'https://[a-z0-9-]+\.trycloudflare\.com' -AllMatches |
         ForEach-Object { $_.Matches.Value } | Select-Object -First 1
    if ($u) { $url = $u; break }
  }
}

if ($url) {
  $content = "星港导航 公网地址`r`n$url`r`n更新时间：$(Get-Date -Format 'yyyy-MM-dd HH:mm:ss')`r`n说明：云电脑或服务重启后地址会变化，重新运行「启动导航站.bat」即可，新地址自动更新到本文件。`r`n"
  [IO.File]::WriteAllText($UrlFile, $content, (New-Object Text.UTF8Encoding $true))
  Write-Host '=============================================='
  Write-Host '  部署完成！公网地址：'
  Write-Host "  $url"
  Write-Host '  地址已保存到：导航站公网地址.txt'
  Write-Host '=============================================='
  if (-not $NoBrowser) { Start-Process $url }
  exit 0
} else {
  Write-Host "隧道未在预期时间内就绪，请稍后重试或检查日志：$CfLog"
  exit 1
}
```

### 4.2 keepalive-nav.ps1（保活检查脚本）

```powershell
# 星港导航 · 保活检查
# 由计划任务每 5 分钟调用；也可手动运行
$ErrorActionPreference = 'SilentlyContinue'
$Root = Split-Path -Parent $MyInvocation.MyCommand.Path
$Port = 8931

# 检查 1：本地 HTTP 服务是否在线（探测回环端口）
$serverOk = $false
try {
  $client = New-Object Net.Sockets.TcpClient
  $client.Connect('127.0.0.1', $Port)
  $serverOk = $client.Connected
  $client.Close()
} catch { $serverOk = $false }

# 检查 2：Cloudflare 隧道进程是否存活（仅匹配本部署的特征）
$cfOk = $false
Get-CimInstance Win32_Process -Filter "Name='cloudflared.exe'" -ErrorAction SilentlyContinue |
  Where-Object { $_.CommandLine -like "*127.0.0.1:$Port*" } |
  ForEach-Object { $cfOk = $true }

if ($serverOk -and $cfOk) {
  Write-Host "$(Get-Date -Format 'yyyy-MM-dd HH:mm:ss') 导航站服务正常，无需处理"
  exit 0
}

Write-Host "$(Get-Date -Format 'yyyy-MM-dd HH:mm:ss') 检测到服务异常（本地服务=$serverOk 隧道=$cfOk），自动重新部署..."
& (Join-Path $Root 'start-nav.ps1') -NoBrowser
```

### 4.3 启动导航站.bat（双击入口）

```bat
@echo off
chcp 65001 >nul
powershell -NoProfile -ExecutionPolicy Bypass -File "%~dp0start-nav.ps1"
pause
```

### 4.4 脚本编写注意事项（在其他机器复现时必读）

1. **PowerShell 中文文件必须存为 UTF-8 with BOM 编码**，否则 Windows PowerShell 5.1 会把中文解析成乱码，导致路径、输出全部损坏。
2. 脚本停止旧进程时按**命令行特征**（`http.server` + 端口号 / `cloudflared` + 回环地址）精确匹配，不会误杀无关的 Python 或其他程序。
3. 隧道日志固定写入 `.temp\cloudflared-latest.log`，地址解析失败时先查这个日志。
4. `导航站公网地址.txt` 用 UTF-8 BOM 写入，用记事本打开不会乱码。

## 五、定时保活配置

### 5.1 TeleAgent 环境内（本部署实际方案）

在 TeleAgent 定时任务中注册 cron 任务（每 15 分钟执行一次保活检查）：

- 任务标题：`星港导航保活检查`
- cron 表达式：`*/15 * * * *`
- 任务内容：运行 `keepalive-nav.ps1`，正常则报告「服务正常」；异常则脚本自动重新部署，并读取 `导航站公网地址.txt` 在回复中附上新地址。

> 说明：在 TeleAgent 云电脑上直接注册 Windows 系统计划任务会被运行时安全策略拦截（`Register-ScheduledTask`/`schtasks` 为受控操作），因此保活改由平台自带定时任务承担。

### 5.2 普通物理机/服务器上（其他机器复现时）

普通 Windows 机器没有上述拦截，可用系统计划任务实现同等保活，以管理员身份运行一次：

```powershell
$action = New-ScheduledTaskAction -Execute 'powershell.exe' `
  -Argument '-NoProfile -ExecutionPolicy Bypass -WindowStyle Hidden -File "keepalive-nav.ps1 的绝对路径"'
$trigger = New-ScheduledTaskTrigger -Once -At (Get-Date).AddMinutes(1) `
  -RepetitionInterval (New-TimeSpan -Minutes 5) -RepetitionDuration (New-TimeSpan -Days 3650)
$settings = New-ScheduledTaskSettingsSet -MultipleInstances IgnoreNew `
  -AllowStartIfOnBatteries -DontStopIfGoingOnBatteries -StartWhenAvailable
Register-ScheduledTask -TaskName 'Starport-NavKeepAlive' `
  -Action $action -Trigger $trigger -Settings $settings -Force
```

如需开机自启，再注册一个 `New-ScheduledTaskTrigger -AtLogon` 触发器调用 `start-nav.ps1 -NoBrowser` 即可。

## 六、常见问题排查（本部署实际遇到）

| 现象 | 原因 | 解决办法 |
|------|------|---------|
| cloudflared 下载超时/速度仅 KB 级 | 直连 GitHub 下载链路被限速 | 换第 3.2 节镜像列表逐个尝试；成功后必须 SHA-256 校验 |
| 公网访问返回 HTTP 530 | 隧道刚注册，边缘节点未传播完 | 等 15–30 秒重试；日志看到 2 条以上 `Registered tunnel connection` 即稳定 |
| 公网地址变了 | 免注册隧道重启后随机更换域名 | 正常现象；查 `导航站公网地址.txt`，或重新运行一键脚本 |
| 530 且长时间不恢复 | 隧道进程退出或本地服务挂了 | 跑 `keepalive-nav.ps1`，或直接双击一键脚本重启 |
| PowerShell 中文输出乱码 | 脚本无 BOM 或控制台代码页不对 | 脚本存 UTF-8 BOM；bat 里 `chcp 65001` |
| 端口被占用 | 8931 被其他程序占用 | 换端口：同步改 `start-nav.ps1`/`keepalive-nav.ps1` 的 `$Port` |
| 想换回公网固定域名 | 免注册隧道地址不固定 | 注册 Cloudflare 账号，用 `cloudflared tunnel login` + 命名隧道绑定自有域名 |

## 七、安全注意事项

1. **最小暴露面**：HTTP 服务仅绑定 `127.0.0.1`、根目录锁定 `nav-deploy`，公网只能看到导航站单页面，工作区其余文件不可达。
2. **二进制可信**：cloudflared 来自官方 release，且经 SHA-256 校验；启用 `--no-autoupdate` 防止自动更新带来的未审计变更。
3. **地址即权限**：公网地址是随机的，但拿到链接的任何人都可访问页面（纯静态、无敏感数据）。如需访问控制，应改用命名隧道 + Cloudflare Access。
4. **数据本地化**：导航站的链接收藏与便签保存在**访问者各自浏览器**的 localStorage 中，不经服务器传输；不同设备数据互相独立。
5. **凭据卫生**：本方案全程无账号、无 API Key，不存在凭据泄漏面。

## 八、复现清单（在其他机器上的最短路径）

1. 拷贝 4 个文件到目标机器同目录：`个人导航站.html`、`start-nav.ps1`、`keepalive-nav.ps1`、`启动导航站.bat`。
2. 按 3.1 节建 `nav-deploy\index.html`；按 3.2 节下载并校验 `cloudflared.exe` 放到 `.temp\tools\`。
3. 确认 Python 可用（`python --version`）。
4. 双击 `启动导航站.bat`，看到公网地址即部署成功。
5. 按第五节配好定时保活，收工。
